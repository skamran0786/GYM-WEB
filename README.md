# Minnat Vigour GYM — Website

Responsive website source for Minnat Vigour GYM, a fitness business in Mumbra/Kausa. The site includes gym information, membership calls to action, and contact links.

## Live Website

https://minnatvigourgym.in/

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Unsplash-hosted photography
- Schema.org structured data

## Main Files

- `index.html` — page content, metadata, structured data, and contact actions
- `styles.css` — layout and responsive styling
- `script.js` — navigation and page interactions

## Run Locally

This is a static website; no package manager is required.

1. Clone the repository:
   ```bash
   git clone https://github.com/skamran0786/GYM-WEB.git
   ```
2. Open the folder in your editor.
3. Open `index.html` directly or use VS Code Live Server.

## Production Checks

- Confirm the business name, address, opening hours, membership prices, phone number, and all offers with the gym before publishing.
- Replace any demo copy or placeholder text with approved business information.
- Test WhatsApp links, navigation, and all forms on a phone and desktop.
- Confirm all photos are permitted for the intended use and have suitable alt text.
- Keep business contact information and structured data consistent with the live website.
